About

RoutePro KSA - Truck Route & Fuel Calculator

A calculator for Saudi Arabia heavy truck logistics. It computes road-route distances, fuel consumption, TGA journey planning compliance, and delay breakdowns for route optimization.

Key Features

  • Road-route calculation with live map preview
  • Journey summary with departure, arrival, and actual journey time
  • Fuel consumption and cost estimation
  • TGA Journey Check with driving limits, breaks, and daily rest planning
  • Delay itemizer for loading, offloading, truck restriction delays, and others
  • Saved routes manager with customer, address, and delay history
  • JSON profile export/import and SQLite database storage

Technology

HTML, JavaScript (Leaflet / OpenStreetMap), SQLite (sql.js), and offline-first localStorage.
